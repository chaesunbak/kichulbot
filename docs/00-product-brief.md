# Product Brief

## 서비스 요약

Kichulbot은 사용자가 기출문제를 풀면 답안 제출 내역을 저장하고, 반복해서 틀리는 문제 유형을 분석해주는 기출문제 풀이 서비스다.

첫 MVP는 한국사 문제로 시작한다. 다만 서비스의 정체성은 한국사 전용 앱이 아니라, 수능과 다른 기출 기반 시험으로 확장 가능한 문제풀이/오답 분석 플랫폼이다.

## 한 줄 정의

기출문제 풀이 기록을 저장하고, 사용자의 약점 유형을 분석해주는 학습 서비스.

## 타깃 사용자

### 초기 타깃

수능 한국사 학습자.

수능 한국사는 첫 시작점으로 적합하다. 필수 응시 과목이라 사용자 풀이 규모가 넓고, 공식 기출문제가 안정적으로 존재하며, 문항 수와 범위가 MVP에서 다루기 좋은 크기다.

한국사능력검정시험도 좋은 도메인이지만, 첫 타깃을 더 넓게 잡는다면 수능 한국사가 더 적합하다. 이후 영어, 탐구, 다른 수능 과목으로 자연스럽게 확장할 수 있기 때문이다.

### 확장 타깃

첫 확장 과목은 수능 영어로 잡는다.

장기적으로는 다른 수능 과목과 기출 기반 시험까지 확장할 수 있다. 다만 초기에는 수능 과목군 안에서 확장하는 것이 사용자 맥락, 문제 데이터 구조, 풀이 경험을 재사용하기 좋다.

## 문제 정의

학습자는 기출문제를 많이 풀지만, 자신이 어떤 유형을 반복해서 틀리는지 명확히 알기 어렵다.

기존 학습 흐름은 대체로 분리되어 있다.

- 문제지를 따로 다운로드한다.
- 답안을 수동으로 채점하거나 단순 기록만 남긴다.
- 오답노트를 직접 만들지 않으면 약점이 누적되지 않는다.
- 문제의 시대, 단원, 주제, 유형이 일관되게 정리되어 있지 않으면 약점 분석으로 이어지기 어렵다.

그 결과 기출 풀이가 반복되더라도, 실제로 어떤 부분이 약한지 진단하기 어렵다.

## 핵심 가치

Kichulbot은 기출문제 풀이를 개인화된 피드백 루프로 바꾼다.

사용자는 서비스를 통해 다음 질문에 빠르게 답할 수 있어야 한다.

- 나는 어떤 유형을 반복해서 틀리는가?
- 어떤 시대, 단원, 주제, 자료 유형을 먼저 복습해야 하는가?
- 내 답안 제출 이력은 시간이 지나며 어떻게 바뀌고 있는가?
- 내가 반복해서 틀리는 유형을 기준으로 무엇을 복습해야 하는가?

## 차별점

핵심 차별점은 단순히 문제를 웹에서 푸는 것이 아니다. 답안 제출 이력과 문제 메타데이터를 연결해 약점 유형을 바로 보여주는 것이다.

주요 차별점은 다음과 같다.

- 사용자의 답안 제출 내역을 저장한다.
- 문제 메타데이터를 기준으로 약점 유형을 분석한다.
- 문제지 또는 문제 세트를 다운로드해 학습 자료로 재사용할 수 있다.
- 관리자가 문제 유형과 분류를 수정하고 품질을 관리할 수 있다.
- 사용자는 잘못된 분류를 제보할 수 있다.
- 한국사로 시작하지만 수능의 다른 과목으로 확장 가능한 구조를 전제로 한다.

## MVP 범위

MVP는 하나의 핵심 루프를 증명하는 데 집중한다.

1. 사용자가 기출문제를 푼다.
2. 서비스가 제출 답안을 저장한다.
3. 문제의 분류 정보와 풀이 결과가 연결된다.
4. 사용자는 자주 틀리는 시대, 단원, 주제, 자료 유형을 확인한다.
5. 사용자는 약점 유형을 기준으로 다시 풀 문제를 선택한다.

### MVP에 포함할 기능

- 문제 이미지 표시
- 객관식 답안 제출
- 답안 제출 내역 저장
- 기본 문제 메타데이터 관리
- 유형별 약점 분석
- 관리자용 문제 분류 수정
- 사용자 분류 오류 제보
- 문제지 또는 문제 세트 다운로드 흐름

### MVP에서 제외할 기능

- 펫 성장 시스템
- 미션 보상
- 포인트 경제
- 랭킹
- 친구 기능
- 고급 통계
- AI 해설 생성
- 모바일 앱
- 사용자별 커스텀 분류

펫과 미션은 장기 비전에는 남긴다. 하지만 첫 MVP에서는 제외한다. 먼저 답안 기록과 약점 분석만으로 사용자가 충분한 가치를 느끼는지 검증해야 한다.

## 제품 원칙

### 문제 풀이가 데이터가 되어야 한다

사용자가 제출하는 모든 답안은 사용자의 학습 상태를 더 잘 이해하는 데이터가 되어야 한다.

### 분류는 고정값이 아니라 학습 도구다

문제의 분류는 약점 분석의 기준이므로 일관되게 관리되어야 한다. MVP에서는 운영자가 분류 품질을 관리하고, 사용자는 오류를 제보할 수 있어야 한다. 사용자별 커스텀 분류는 MVP 이후 확장 기능으로 검토한다.

### 좁게 시작하되 넓게 설계한다

첫 콘텐츠는 한국사지만, 도메인 모델은 여러 시험, 과목, 단원, 주제, 사용자 정의 태그를 지원할 수 있어야 한다.

### 분석은 즉시 보여야 한다

사용자가 별도의 오답노트를 만들지 않아도, 지금 어떤 부분이 약한지 바로 확인할 수 있어야 한다.

## 장기 비전

Kichulbot은 사용자가 기출문제를 가져오고, 풀고, 분류하고, 다운로드하고, 복습할 수 있는 개인화 기출 학습 워크스페이스가 되는 것을 목표로 한다.

서비스는 사용자의 풀이 기록을 바탕으로 강점과 약점 지도를 계속 업데이트한다. 나중에 추가될 게임 요소는 이 학습 루프를 보조해야 한다.

펫과 미션 시스템은 다음 역할을 담당할 수 있다.

- 미션은 다음에 풀 문제와 복습 방향을 추천한다.
- 포인트는 꾸준한 복습을 보상한다.
- 펫은 사용자의 학습 진행 상태를 시각적으로 보여준다.

## 열어둘 질문

- 첫 문제 데이터는 수능 한국사 공식 기출만 사용할 것인가, 교육청/사설 모의고사까지 포함할 것인가?
- MVP에서 사용자의 분류 오류 제보는 어떤 화면과 흐름으로 받을 것인가?
- 사용자별 커스텀 분류는 어느 시점에 다시 검토할 것인가?
- 최소 약점 분석 단위는 시대/단원/주제까지만 둘 것인가, 자료 유형과 문제 형식까지 포함할 것인가?
- 문제지 다운로드 기능은 저작권과 출처 표기를 어떻게 처리할 것인가?
