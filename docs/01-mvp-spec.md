# MVP Spec

## MVP 목표

첫 MVP의 목표는 수능 한국사 1개년 기출문제지를 사용자가 웹에서 풀고, 제출한 답안 기록을 기반으로 태그별 약점과 오답을 확인할 수 있게 만드는 것이다.

이 단계에서는 게임 요소보다 문제풀이, 기록 저장, 약점 분석, 오답 복습의 기본 루프를 검증한다.

## 핵심 사용자 시나리오

1. 사용자가 게스트로 시작하거나 회원가입/로그인한다.
2. 사용자가 문제지 목록에서 수능 한국사 1개년 문제지를 내 서재에 추가한다.
3. 사용자가 내 서재에서 문제지를 선택해 20문항을 푼다.
4. 서비스가 각 문항의 제출 답안과 정오답을 저장한다.
5. 사용자가 결과 화면에서 점수, 정답률, 틀린 문제를 확인한다.
6. 사용자가 태그별 약점 분석을 확인한다.
7. 사용자가 틀린 문제만 다시 푼다.

## MVP에 포함할 기능

### 인증

- 게스트 시작
- 게스트 사용자의 답안 기록 저장
- 게스트 사용자의 이메일 계정 전환
- 이메일 기반 회원가입
- 이메일 기반 로그인
- 로그아웃
- 로그인한 사용자별 답안 기록 저장
- access token은 `Authorization: Bearer {accessToken}` 헤더로 전달

소셜 로그인과 이메일 인증 메일 발송은 MVP에서 제외한다. MVP에서는 게스트로 먼저 문제를 풀 수 있게 하고, 회원가입 시 기존 게스트 기록을 이메일 계정으로 전환한다.

### 문제지

- 관리자 문제지 등록
- 문제지 목록 조회
- 문제지를 내 서재에 추가
- 내 서재에 추가한 문제지 조회
- 내 서재에서 문제지 풀이 시작

여기서 "다운로드"는 실제 파일을 컴퓨터에 저장하는 기능이 아니다. 사용자가 서비스 안에서 문제지를 가져와 자신의 서재에 추가하는 흐름을 의미한다.

### 문제 등록

- 관리자가 수동으로 문제를 입력한다.
- 문제는 이미지 기반으로 등록한다.
- 각 문제에는 정답과 태그를 함께 등록한다.
- MVP의 첫 데이터 범위는 수능 한국사 1개년 20문항이다.

### 문제 풀이

- 사용자는 1개년 문제지 단위로 푼다.
- 한 문제지는 20문항으로 구성한다.
- 각 문항은 문제 이미지와 `choiceCount` 기반 답안 선택 버튼을 보여준다.
- 사용자는 문항별 답안을 선택한다.
- 문항 선택 시 답안을 임시 저장한다.
- 최종 제출 후 정오답을 저장한다.
- 결과 화면에서 전체 점수와 틀린 문제를 확인한다.
- MVP의 기본 풀이 화면은 한 번에 한 문제씩 보여준다.
- 전체 문제를 한 화면에서 푸는 방식은 이후 선택형 보기로 확장한다.

### 태그와 약점 분석

- 한 문제는 여러 개의 태그를 가질 수 있다.
- MVP에서는 시대 태그만 사용한다.
- 태그별 풀이 수, 정답 수, 오답 수, 정답률을 보여준다.
- 태그별 정답률을 기준으로 약점 유형을 확인한다.

초기 시대 태그:

- 선사
- 고대
- 고려
- 조선
- 근대
- 일제강점기
- 현대

### 오답 복습

- 서비스는 매일 갱신되는 오답 문제지를 만든다.
- 사용자는 오늘의 오답 문제지를 볼 수 있다.
- 사용자는 오답 문제지에 포함된 문제만 다시 풀 수 있다.
- 다시 푼 기록도 답안 기록으로 저장한다.

## MVP에서 제외할 기능

- 소셜 로그인
- 펫 성장 시스템
- 미션 보상
- 포인트 경제
- 사용자별 커스텀 분류
- 섹션별/주제별 상세 태그 분석
- 문제지 PDF 생성
- 실제 파일 다운로드
- 문제 자동 추출
- 해설 입력 및 표시
- 서술형 답안 입력
- AI 해설 생성
- 랭킹
- 친구 기능
- 모바일 앱

## 화면 목록

### 사용자 화면

- 로그인 화면
- 회원가입 화면
- 게스트 시작 화면 또는 버튼
- 문제지 목록 화면
- 내 서재 화면
- 문제지 풀이 화면
- 풀이 결과 화면
- 약점 분석 화면
- 오답 복습 화면

### 관리자 화면

- 관리자 문제지 목록 화면
- 관리자 문제지 등록 화면
- 관리자 문제 등록 화면
- 관리자 문제 수정 화면

## 핵심 플로우

### 문제지를 내 서재에 추가

1. 사용자가 로그인한다.
2. 문제지 목록으로 이동한다.
3. 수능 한국사 1개년 문제지를 선택한다.
4. "내 서재에 추가"를 누른다.
5. 내 서재에서 해당 문제지를 확인한다.

### 문제지 풀이

1. 사용자가 내 서재에서 문제지를 선택한다.
2. 20문항 문제 풀이 화면으로 이동한다.
3. 사용자가 각 문항의 답안을 선택한다.
4. 사용자가 답안을 제출한다.
5. 서비스가 답안 기록과 정오답을 저장한다.
6. 결과 화면으로 이동한다.

### 약점 분석

1. 사용자가 약점 분석 화면으로 이동한다.
2. 서비스가 사용자의 답안 기록을 태그별로 집계한다.
3. 사용자는 시대 태그별 정답률과 오답 수를 확인한다.
4. 사용자는 정답률이 낮은 태그를 약점으로 인식한다.

### 오답 복습

1. 사용자가 오답 복습 화면으로 이동한다.
2. 서비스가 사용자가 틀린 문제를 보여준다.
3. 사용자가 틀린 문제만 다시 푼다.
4. 서비스가 다시 푼 답안 기록을 저장한다.

## 데이터 범위

### 첫 문제지

- 시험: 수능
- 과목: 한국사
- 범위: 1개년
- 문항 수: 20문항
- 문제 형식: 객관식
- 문제 본문: 이미지
- 태그 범위: 시대 태그

### 문제별 필수 데이터

- 문제 이미지
- 문제 번호
- 선택지 개수
- 정답
- 시대 태그
- 시험명
- 과목명
- 시행 연도

## 성공 기준

MVP는 다음 조건을 만족하면 성공으로 본다.

- 사용자가 게스트로 시작할 수 있다.
- 사용자가 회원가입/로그인할 수 있다.
- 게스트 사용자가 회원가입하면 기존 기록이 유지된다.
- 관리자가 수능 한국사 1개년 20문항을 등록할 수 있다.
- 사용자가 문제지를 내 서재에 추가할 수 있다.
- 사용자가 1개년 문제지를 끝까지 풀고 제출할 수 있다.
- 문항 선택 시 임시 답안이 저장된다.
- 사용자별 답안 기록이 저장된다.
- 결과 화면에서 점수와 틀린 문제를 확인할 수 있다.
- 시대 태그별 정답률과 오답 수를 확인할 수 있다.
- 매일 갱신되는 오답 문제지를 다시 풀 수 있다.

## 결정된 것

- 첫 MVP는 수능 한국사 1개년 20문항으로 시작한다.
- 게스트 시작을 지원한다.
- 게스트 사용자는 이메일 회원가입 시 기존 기록을 유지한 채 이메일 계정으로 전환된다.
- access token은 `Authorization` 헤더로 전달한다.
- 이메일 인증 메일은 MVP에서 발송하지 않는다.
- 문제는 이미지 기반으로 등록한다.
- 문제 등록은 관리자가 수동으로 한다.
- 사용자는 문제지를 실제 파일로 다운로드하지 않고, 서비스 안의 내 서재에 추가한다.
- 문제는 여러 태그를 가질 수 있는 구조로 설계한다.
- MVP에서는 시대 태그만 사용한다.
- 문제 풀이는 1개년 문제지 단위로 한다.
- 기본 풀이 화면은 한 번에 한 문제씩 보여준다.
- 답안은 문항 선택 시 임시 저장하고, 최종 제출 시 정오답을 저장한다.
- 오답 복습은 매일 갱신되는 오답 문제지로 제공한다.
- 객관식 선택지는 텍스트로 저장하지 않고 선택지 개수만 저장한다.
- MVP에서는 해설을 입력하거나 표시하지 않는다.
- 펫, 미션, 포인트는 MVP에서 제외한다.
